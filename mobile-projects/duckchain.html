What is DuckChain? (The First TON-Based EVM Layer 2)

DuckChain is an innovative consumer Layer-2 blockchain protocol built directly to connect the TON (Telegram Open Network) ecosystem with the global Ethereum Virtual Machine (EVM) landscape. Built leveraging Arbitrum Orbit execution scaling, DuckChain allows Telegram's massive user base of over 900 million users to seamlessly interact with EVM-compatible decentralized finance (DeFi), gaming dApps, and non-fungible digital assets without switching networks or managing multiple complex wallets.

The project bridges the liquidity gap between Ethereum, Arbitrum, and Telegram by introducing an account abstraction layer where Telegram Stars, TON, and USDT function natively as gas mechanisms. Backed by key industry leaders and top-tier Web3 ventures, DuckChain establishes a consumer-first blockchain gateway that turns simple Telegram interactions into verified on-chain assets.
