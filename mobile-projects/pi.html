Origin & Architecture: What is Pi Network?

Pi Network is a mobile-first Layer-1 social cryptocurrency protocol launched on March 14, 2019 (Pi Day) by Stanford PhD graduates Dr. Nicolas Kokkalis and Dr. Chengdiao Fan[cite: 9]. It was specifically engineered to solve the massive environmental waste, hardware barriers, and institutional mining cartels that dominate traditional Proof-of-Work (PoW) networks like Bitcoin[cite: 9].

Instead of forcing devices to solve complex mathematical puzzles with heavy electricity draw, Pi allows everyday smartphone users to participate in distributed consensus by checking in once every 24 hours[cite: 9]. Operating inside a secure, lightweight sandboxed mobile interface, the app generates zero battery drainage, zero CPU overheating, and zero background data tracking[cite: 9].

Consensus Engine: Stellar Protocol & Security Circles

Pi Network does not perform hash-based hardware mining[cite: 9]. Its underlying ledger is powered by an implementation of the Stellar Consensus Protocol (SCP), governed by Federated Byzantine Agreement (FBA):

🌐 1. Security Circles & Quorum Slices

Network integrity is maintained through individual Security Circles composed of 3 to 5 trusted peers vouched for by each pioneer[cite: 9]. These interconnected circles form a global trust graph, allowing the decentralized ledger to determine which transactions are legitimate without wasting electrical power[cite: 9].

⚡ 2. The Four Ecosystem Roles

Pioneers verify active daily human participation; Contributors fortify the trust graph via completed security circles[cite: 9]; Ambassadors onboard genuine global users; and Node Operators run the core SCP validation software across personal computers to execute decentralized block validation.

🔒 3. Non-Custodial Wallet Ledger

The native Pi Wallet operates with an independent 24-word cryptographic seed phrase. Pioneers retain complete self-custody of their keys on the Layer-1 mainnet, accessible directly through the dedicated decentralized Pi Browser[cite: 9].
