What is Pi Network? (Mobile-First Layer 1 Architecture)

Pi Network is an independent Layer-1 cryptocurrency protocol established on March 14, 2019, by Stanford PhD researchers Dr. Nicolas Kokkalis and Dr. Chengdiao Fan[cite: 9]. It was created to provide a decentralized alternative to traditional Proof-of-Work (PoW) blockchains like Bitcoin, which demand massive electricity consumption and expensive mining rigs[cite: 9].

Pi replaces heavy cryptographic computation with a lightweight consensus model. Users verify their daily presence by checking in once every 24 hours via smartphones with zero battery drainage, zero CPU load, and no background resource consumption[cite: 9].

2

How Pi Network Operates: The SCP Consensus Engine

Instead of hash mining, Pi's blockchain runs on an implementation of the Stellar Consensus Protocol (SCP)[cite: 9]:

• Security Circles: Pioneers build trust circles of 3 to 5 trusted members[cite: 9]. These interconnected circles form a global trust graph that helps the network validate transactions without burning energy[cite: 9].
• Multi-Tier Roles: Everyday users participate as Pioneers and Contributors[cite: 9], while dedicated PC users run the desktop Pi Node to compute consensus and secure the distributed ledger.
• Self-Custody Keys: Balances migrate to independent non-custodial wallets controlled exclusively by a 24-word Passphrase through the decentralized Pi Browser[cite: 9].

Tokenomics & Maximum Supply Hard-Cap

Pi's economic issuance follows a fixed mathematical rule[cite: 9]:
