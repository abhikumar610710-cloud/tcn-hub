📖 Project Overview: What is Pi Network?

Pi Network is a utility-driven social cryptocurrency and decentralized developer infrastructure founded on March 14, 2019, by Stanford PhD scholars Dr. Nicolas Kokkalis and Dr. Chengdiao Fan. It was engineered to solve the extreme barriers to entry inherent in traditional Proof-of-Work (PoW) protocols—specifically hardware expenses, electricity overhead, and institutional mining centralisation.

Pi pioneered smartphone-native consensus using an implementation of the Stellar Consensus Protocol (SCP) and Federated Byzantine Agreement (FBA). Users secure the ledger by maintaining active Security Circles of 3 to 5 trusted peers rather than conducting computationally intensive hashing routines.

⚡ Consensus Mechanics: Security Circles & Nodes

The Pi protocol implements a multi-tier participation structure to maintain Sybil resistance and distributed security:

• Pioneers: Verify daily active presence by checking in once every 24 hours via mobile devices, generating zero CPU heat or energy draw.
• Contributors: Build 100% Security Circles with 3 to 5 trusted connections, forming interlocking trust graphs required by FBA quorum slices.
• Ambassadors: Expand ecosystem adoption and earn fractional base-rate acceleration.
• Desktop Nodes: Compute the decentralized SCP consensus engine across personal computers, verifying blocks and maintaining the distributed ledger.

🛡️ Security Protocol: Seed Phrase Safeguards
