Origin & Architecture: What is Pi Network?

Pi Network is a mobile-first Layer-1 social cryptocurrency protocol launched on March 14, 2019 (Pi Day) by Stanford University PhD scholars Dr. Nicolas Kokkalis and Dr. Chengdiao Fan[cite: 9]. It was specifically engineered to solve the extreme barriers to entry inherent in traditional Proof-of-Work (PoW) networks like Bitcoin—specifically astronomical electricity consumption, specialized ASIC mining hardware costs, and mining pool centralisation[cite: 9].

Rather than conducting hash-based computations on device silicon, Pi allows everyday smartphone users to participate in distributed consensus by checking in once every 24 hours[cite: 9]. The client operates inside a sandboxed mobile application requiring Zero Energy Draw, Zero CPU Load, and zero disruption to daily cellular operations[cite: 9].

Consensus Engine: Stellar Protocol & Security Circles

Pi Network operates an implementation of the Stellar Consensus Protocol (SCP), governed by Federated Byzantine Agreement (FBA)[cite: 9]:

🌐 1. Security Circles & Quorum Slices

Network integrity is maintained through individual Security Circles composed of 3 to 5 trusted peers vouched for by each pioneer[cite: 9]. These interconnected circles form a global trust graph, allowing the decentralized ledger to determine transaction legitimacy without burning electrical power[cite: 9].

⚡ 2. The Multi-Tier Network Roles

Pioneers verify active daily human presence; Contributors fortify the global trust graph via 100% security circles[cite: 9]; Ambassadors onboard authenticated participants; and Node Operators run the core SCP validation daemon across personal computers to execute decentralized block validation.

🔒 3. Self-Custody Pi Browser & Non-Custodial Wallet

Native balances are secured through a non-custodial cryptographic wallet anchored by an independent 24-word Passphrase. Pioneers maintain exclusive custody of their Layer-1 private keys through the dedicated decentralized Pi Browser[cite: 9].
