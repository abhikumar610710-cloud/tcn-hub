1 What is CoinSwitch?

CoinSwitch is an India-focused cryptocurrency trading and investing platform. Its official website lists INR-based Spot trading, Futures, Options, US-market perpetual contracts, commodities perpetuals and Web3 coins. CoinSwitch PRO also presents advanced charting and API trading tools for eligible users.

A CoinSwitch exchange account is not the same as a self-custody wallet. Review how each product holds or accesses assets, the applicable terms, order execution details and withdrawal conditions before using it.

Proof of Reserves — understand the scope

CoinSwitch says it publishes periodic Proof of Reserves information reviewed by a third-party accountant. Read the actual report, snapshot date, asset scope and methodology before drawing conclusions. A Proof of Reserves report is a point-in-time transparency measure; it is not deposit insurance and cannot remove market, operational, custody or regulatory risk.

Developer note: CoinSwitch PRO API

CoinSwitch's developer documentation describes separate Spot, Futures, HFT and Options API surfaces. The documented authentication uses API-key and Ed25519 signature headers. Do not put an API secret or private signing key in front-end HTML/JavaScript, a public GitHub repository or a browser. Use a secure server-side integration, restricted permissions and key rotation. Options API access is described as private beta in the API-surface documentation.

5 Security Tips

  • 🛡️Use the official domain. Check that the address is coinswitch.co and beware of lookalike links and fake support profiles.
  • 🔐Protect login credentials and OTPs. Never disclose passwords, OTPs, API secrets or private keys to anyone.
  • 🔎Review every order. Check the asset, quantity, order type, price, charges and settlement details before confirming.
  • 🧰Restrict API permissions. Keep keys off public repositories and disable compromised keys immediately.
  • ⚠️Beware of guaranteed-return claims. No trading strategy or platform feature can guarantee profit.
