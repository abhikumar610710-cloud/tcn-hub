1 What is Delta Exchange?

Delta Exchange India is a digital-asset trading platform operated by Excelium Technologies Private Limited. Its India platform offers Spot trading in BTC, ETH, SOL and XRP, along with crypto derivatives such as Futures and Options on Bitcoin and Ether. The official platform also lists selected real-world-asset products and trading tools.

Spot trading means buying or selling the supported asset directly without using derivatives leverage. Futures and Options are different products: they involve contract terms, margin, expiry or funding mechanics, and can create rapid losses. Read the instrument specifications and fee schedule before trading.

Beginner Note

Start by learning Spot orders, spreads, order types and fees. Do not confuse INR margin/settlement with the contract's displayed quotation unit. Derivatives and leverage are complex; understand liquidation, funding, expiry and settlement before considering them.

Contract quotation vs settlement currency

For example, Delta's BTCUSD contract specification lists price quotation in USD per BTC while margin and effective settlement currency are INR. This is why a displayed contract price should not automatically be labelled as an INR amount. Check each product's contract specification for quote currency, lot size, margin, fees and funding details.

6 Security & API Safety

  • 🛡️Use the official domain. Check the address carefully and avoid lookalike sites, unsolicited links and fake support profiles.
  • 🔐Protect login credentials. Use a unique password and enable the security methods currently offered in your account.
  • 🔑Keep API secrets private. Never paste API keys or secrets into public HTML, GitHub, client-side JavaScript, chats or screenshots.
  • ✋Review every order. Confirm contract symbol, quantity, direction, order type, margin, fees and liquidation implications.

Delta's API docs say public market ticker endpoints do not require authentication, while account-related and order-placement endpoints require API key/secret authentication. Private credentials must never be embedded in front-end code. API authentication and security documentation ↗
