What is MetaMask? (Self-Custodial EVM Wallet)

How MetaMask Works (All-in-One Flow)

🔐 1. Create Wallet

Set password, get 12-word Secret Recovery Phrase, store offline on paper.

🌐 2. Add Network

Ethereum by default. Add BNB, Polygon, Arbitrum, Base, Avalanche in 1 click.

💸 3. Send / Receive / Swap

Copy address to receive, send tokens, swap inside wallet without exchange.

🧩 4. Connect to Web3

Click Connect Wallet on any dApp, approve transactions, sign securely.

Security & Safety - Mandatory Rules

⚠️ Mandatory Safety Rules:

  1. Never Share Seed Phrase: MetaMask team will NEVER ask for it. Anyone asking = scam.
  2. One Wallet = One Backup: Write phrase on paper, never screenshot or store in Google Drive / Telegram.
  3. Verify Every Transaction: Check address, network and gas before Approve. Revoke unknown permissions.
  4. Use Hardware Wallet for Large Funds: Connect Ledger for extra protection.

✅ DO

• Use official site metamask.io
• Lock wallet after use
• Update extension regularly

❌ DON'T

• Click random airdrop links
• Import unknown tokens
• Connect to unknown dApps
