1 What is Rabby Wallet?

Rabby Wallet is a self-custody crypto wallet designed for Ethereum and EVM-compatible networks. It helps users manage wallet accounts, connect to decentralized applications (DApps), and review blockchain transactions.

One of Rabby's distinctive features is its transaction preview: before you approve a supported transaction, the wallet can show an estimated view of asset and balance changes and display potential risk warnings. This is useful information, but it is not a guarantee that a transaction or website is safe.

💡

Quick Fact

Rabby focuses on Ethereum and EVM-compatible networks. Network availability can change, so check Rabby's official supported-network information before using a specific chain or DApp.

5 Security Tips

  • 🛡️Protect your recovery phrase. Never share it with anyone, including people claiming to be wallet support.
  • 🔎Check the official URL. Use rabby.io and verify extension publishers before installing.
  • 📋Read the transaction preview. Check assets leaving and arriving, approvals, network and destination.
  • ⚠️Do not rely only on automated warnings. Simulations and scanners can miss risks or show incomplete information.
  • 🔐Review permissions regularly. Disconnect unused DApps and review token approvals where the wallet or relevant network provides that option.
