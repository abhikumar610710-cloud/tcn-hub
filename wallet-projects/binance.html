1 What is Binance?

Binance is a centralized cryptocurrency exchange (CEX) and broader blockchain ecosystem. Its services include digital-asset markets and tools such as Spot trading, Convert, P2P, derivatives, Earn products and learning resources. Available products, payment methods and trading pairs can vary by country and account eligibility.

Important custody difference: an exchange account is not the same as a self-custody wallet. Assets held in an exchange account are managed through the platform’s account and custody systems. Users should understand withdrawal rules, account terms and counterparty/platform risks before depositing funds.

💡

Beginner Note

Binance’s beginner guide recommends setting up an account, completing any required identity verification, learning the Convert or Spot interface, and securing the account with a strong password, 2FA and an anti-phishing code.

5 Account Security Tips

  • 🛡️Enable two-factor authentication. Use supported 2FA or passkey options and secure your email account too.
  • 🔎Check the website domain. Avoid links in unexpected messages, fake support accounts and lookalike websites.
  • 📩Set an anti-phishing code. Check that genuine Binance messages display the code you configured.
  • 🔐Use withdrawal address controls. Consider enabling the withdrawal address whitelist and verify every destination.
  • ✋Never share credentials or codes. Do not share passwords, OTPs, 2FA codes, API secrets or remote access with anyone.

These security measures are based on Binance’s own account-security and anti-phishing guidance. No security feature can remove every risk. Binance account security ↗ · Anti-phishing code guide ↗
