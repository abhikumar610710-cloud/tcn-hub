What is Gradient Network? (AI Public Good)

Gradient Network is a highly anticipated DePIN project aimed at decentralizing artificial intelligence. Its mission is to transform AI into a shared public good by moving heavy AI workloads away from closed corporate data centers and onto an open layer of collective intelligence hosted on consumer devices.

Instead of relying solely on expensive server farms, Gradient breaks down massive Large Language Models (LLMs) so they can be processed and routed across thousands of everyday devices (like your PC's CPU/GPU and internet bandwidth) privately and securely.

The Core Technical Stack (How it Works)

Gradient utilizes three distinct architectural layers to handle complex AI workloads across consumer hardware:

🌐 Lattica

A universal peer-to-peer data communication protocol. It serves as the connectivity backbone for global edge communication.

🧠 Parallax

A fully distributed LLM inference engine. It orchestrates collaborative AI execution across heterogeneous devices (from enterprise GPUs to Apple Silicon).

⚙️ Echo / Echo-2

An async distributed reinforcement learning framework that manages AI model training while optimizing for fluctuating or unreliable edge nodes.

☁️ Gradient Cloud

A public-facing inference platform acting as a unified API gateway hosting open foundation models like DeepSeek V3.2.

Earning via Sentry Nodes (Browser Extension)

Currently, in its open beta phase, the primary way for the general public to participate and earn airdrop points is by running a Sentry Node.

🛡️ How Sentry Nodes Work:

1. Ultra-Low Overhead: You do not need a high-end GPU to start. Users install a lightweight desktop browser extension (via the Chrome Web Store) that consumes less than 1 MB of data per month to route data pings and verify network connectivity.

2. Passive Point Generation: By keeping the extension running 24/7, you passively accumulate "Taps" and Experience Points (EXP). These points track your Proof-of-Availability (POA) and Proof-of-Connectivity (POC) for future token airdrops.

3. Strict IP Rules: The system enforces a strict rule of one account per physical machine. If you run multiple Sentry extensions on the same Wi-Fi IP address, the network will automatically split your reward yield.
