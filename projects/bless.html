📱 Android Mobile Setup Guide (Mises / Kiwi Web3 Browser)

Run the Bless Extension Node directly on your Android smartphone using an extension-supported mobile browser to accumulate uptime points over mobile Wi-Fi.

1
Install Mises Browser or Kiwi Browser
Download and install Mises Browser or Kiwi Browser from the Google Play Store on your Android device.
2
Add Bless Extension to Mobile Browser
Inside Mises or Kiwi, open the Chrome Web Store, search for Bless Extension Node, and tap Add to Chrome.
3
Log In with Referral Code GUKQ7Q
Open your mobile browser extension menu, launch Bless, and sign in with your registered account. Confirm that your status shows an active green "Online" state.
4
Enable Unrestricted Background Execution
To maintain steady uptime without Android terminating the browser:
  • Go to phone Settings → Apps → Mises / Kiwi → Battery.
  • Select Unrestricted / No Restrictions (Don't optimize).
  • Lock the browser in your Recent Apps screen with the padlock icon.
