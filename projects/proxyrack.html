🐳 Docker Container Guide (Headless Mini PC & Linux Server)

Running PeerRack inside a Docker container is the recommended deployment for 24/7 low-power mini PCs, Raspberry Pi, and Linux home servers.

1
Verify Docker Installation
Ensure Docker Engine or Docker Desktop is active on your host system. Test with docker --version in your terminal.
2
Pull Official Proxyrack Peer Client Image
Open your terminal and pull the latest production container from the official repository:
docker pull proxyrack/pop:latest
3
Run Container with Your Device Key / API Token
Launch the container with your device key retrieved from your PeerRack web dashboard (replace YOUR_API_KEY with your unique token):
docker run -d --name proxyrack-peer \
  --restart unless-stopped \
  -e API_KEY="YOUR_API_KEY" \
  proxyrack/pop:latest
4
Verify Runtime Logs & Connection Status
Confirm that the node has authenticated and connected to the residential relay network:
docker logs -f proxyrack-peer
💡 Mini PC Hardware Advantage:

The Docker container requires less than 25MB of RAM and almost 0% CPU, making it lightweight and stable for continuous residential monetization.
