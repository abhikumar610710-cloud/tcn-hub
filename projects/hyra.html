💻 Windows PC Setup Guide (Docker Desktop Container Node)

Hyra AI utilizes distributed compute cycles to power machine learning inference models. On Windows, the node executes natively inside Docker Desktop to isolate processes safely.

1
Register on Hyra AI Web Portal
Visit Hyra AI Registration Portal. Connect your Web3 wallet or sign up using your email. The invite key ref-24927de1a5481 binds your node to the verified compute rewards tier.
2
Verify Hardware & Install Docker Desktop
Ensure hardware virtualization (VT-x / AMD-V) is enabled in your PC BIOS. Download and install Docker Desktop (with WSL2 Linux backend). Recommended minimum configuration: Quad-Core / Core i5 / Core i7 processor and at least 8GB to 16GB RAM for uninterrupted inference execution.
3
Obtain Node Identity Key & Run Container
Navigate to your Hyra dashboard, open the Nodes section, and copy your assigned Identity API Token. Open Windows Terminal (PowerShell) and execute the official pull-and-run container script:
docker pull hyranetwork/hyra-node:latest
docker run -d --name hyra-compute-node --restart always -e NODE_KEY=YOUR_KEY hyranetwork/hyra-node:latest
4
Confirm Active Node Telemetry
Check Docker Desktop to ensure the container status indicates Running. Refresh your Hyra AI web dashboard to confirm the node has established heartbeat telemetry and is actively logging compute uptime points.
💡 Compute Allocation Safety:

The Docker container operates in an isolated sandbox. It only accesses the allocated CPU threads and idle bandwidth specified by the daemon. Your private files, personal operating system data, and credentials remain strictly isolated.
