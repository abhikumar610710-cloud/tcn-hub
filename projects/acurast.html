What is Acurast? (Decentralized Compute)

Acurast is a revolutionary decentralized, verifiable, and highly confidential cloud computing network (DePIN Compute). Instead of relying on centralized corporate data centers, Acurast aggregates the processing power of old, unused, and active smartphones globally to construct an immense distributed supercomputer.

What sets Acurast apart is its utilization of the smartphone's Trusted Execution Environment (TEE). This secure, isolated chipset area ensures that all data processed on your device remains completely confidential and the execution code cannot be tampered with. It is heavily utilized by developers for AI edge inference (LLMs), secure data scraping, and executing robust blockchain oracles.

Hardware Support (Mobile-Exclusive Ecosystem)

Acurast abandons traditional PCs, VPS servers, and browser extensions entirely. The entire architecture relies exclusively on smartphone hardware attestation:

📱 Processor Lite

Available on iOS and Android. This version allows users to contribute background compute power on their primary, everyday smartphones without disrupting daily usage.

🚀 Acurast Core

Designed for professional node runners. You can factory-reset an old, unused smartphone, scan an onboarding QR code via the Acurast Hub, and convert it into a dedicated 24/7 high-yield compute node.

⚙️ The Compute Score Weighting

Your earning capacity is strictly determined by hardware benchmarks, NOT internet speed. Device rewards are weighted by CPU performance (46.15%), RAM capacity (46.15%), and Storage (7.69%).

🚫 No VPS or Desktop Proxies

Running Acurast on an emulator or data-center VPS is entirely futile. The network cryptographically verifies the physical presence of a mobile TEE chip (Hardware Attestation) before accepting compute power.

Network Rules & The "Phone Farm" Advantage

Because Acurast monetizes pure processing power rather than IP bandwidth, it allows for highly scalable, localized setups:

💡 TCN Scaling Tip: Unlimited Devices per IP
