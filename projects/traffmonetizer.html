🐳 Docker Container Guide (Headless Mini PC & Linux Server)

Running TraffMonetizer in Docker is the most energy-efficient setup for 24/7 low-power mini PCs, Raspberry Pi, and Linux home servers.

1
Verify Docker Installation
Ensure Docker Engine or Docker Desktop is active on your host system. Test with docker --version in your terminal.
2
Pull Official TraffMonetizer Docker Image
Open terminal and pull the official multi-architecture container:
docker pull traffmonetizer/cli_v2:latest
3
Run Container with Your Application Token
Execute the container with your personal token (replace YOUR_TOKEN_HERE with your dashboard token):
docker run -d --name tm \
  --restart unless-stopped \
  traffmonetizer/cli_v2:latest start accept --token YOUR_TOKEN_HERE
4
Verify Runtime Logs
Check that the daemon has successfully handshaked with the proxy network:
docker logs -f tm
💡 Mini PC Hardware Advantage:

The Docker container requires less than 20MB of RAM and almost 0% CPU, making it seamless to run alongside your other DePIN nodes.
