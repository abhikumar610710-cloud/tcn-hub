What is Teneo Protocol? (AI Data Layer)

Teneo Protocol is a sophisticated DePIN (Decentralized Physical Infrastructure Network) and AI data platform. It moves beyond simple bandwidth sharing by actively transforming live, unstructured public web streams into structured, high-value intelligence for AI agents and developers.

By running a node, everyday users crowdsource public social media data and web streams. Teneo's Live-Web Execution Layer then allows AI agents to access this live data, search tools, and cross-chain market intelligence through a pay-per-result model (via USDC), bypassing the need for expensive, centralized API subscriptions.

Earning "Fragments" (Nodes & The Beacon)

Teneo offers multiple entry points for node operators, each with varying reward structures based on their hardware capabilities:

🌐 Community Node (Extension)

A lightweight browser extension (Chrome). It runs silently in the background, requiring a stable Residential IP. No GPU or dedicated storage is required.

🚀 Teneo Beacon (Native App)

A standalone desktop app (Windows/macOS/Linux). Running the native Beacon unlocks massive potential, offering up to a 2x point multiplier and unlocking extra Fragment rewards across multiple devices.

⏱️ The 8-Hour Claim Cycle

Unlike purely passive apps, Teneo rewards active engagement. Users must manually claim their rewards every 8 hours in the Beacon app to stack a "Beacon Power Multiplier" up to 3.00x.

📉 Multiplier Decay

Consistency is key. If you miss your 8-hour claim windows, your 3.00x multiplier will slowly decay back to the baseline.
