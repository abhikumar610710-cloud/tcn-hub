💻 Windows Desktop Node Setup Guide (24/7 Persistent Uptime)

The ARO Windows Desktop client operates as an independent background daemon in your system tray, delivering consistent uptime without relying on open browser windows.

1
Download the Official Windows Client
Sign in to your account at ARO Network Dashboard. Navigate to the Download Nodes section and choose the Windows (.exe) installer.
2
Install & Authenticate Your Desktop Node
Run the setup wizard, launch the desktop application, and enter your account login details. The client pairs your PC hardware identity with your web dashboard profile.
3
Configure Auto-Start Settings
In the app settings, toggle ON "Launch on System Startup". This ensures the ARO daemon resumes background node operation immediately if your PC restarts.
4
Verify System Tray Execution
Minimize the window to your Windows System Tray (near the clock). The node operates silently in the background with negligible memory and CPU consumption.
💡 Desktop Uptime Benefit:

Desktop clients prevent browser sleep tabs from pausing bandwidth verification, yielding higher long-term uptime consistency on desktop PCs and mini PCs.

📱 Android Mobile Node Setup Guide (Mobile Background Sharing)

The official ARO Protocol Android application allows smartphone users to monetize idle mobile and Wi-Fi connectivity on the go.

1
Download Official Android Client
Register your account via ARO Mobile Signup with code GQZ6QW. Download the official Android APK or Google Play release provided in your dashboard.
2
Sign In & Grant Background Network Permissions
Open the ARO app, log in with your verified credentials, and grant the requested background network service permissions to initialize the edge node.
3
Set Battery Optimization to "No Restrictions"
To prevent aggressive OEM power management from terminating the node:
  • Navigate to phone Settings → Apps → ARO Protocol → Battery.
  • Select Unrestricted / No Restrictions (Don't optimize).
  • Enable Autostart permissions.
  • Lock the app in your Recent Apps screen using the padlock icon.
4
Confirm Active Mobile Telemetry
Verify that the app shows "Connected / Earning". You can choose in the app settings whether to share via Wi-Fi only or include mobile data.
