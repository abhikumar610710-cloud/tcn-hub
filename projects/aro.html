What is ARO Network? (The Edge Cloud Platform)

Backed by heavyweights like No Limit Holdings, Dispersion Capital, and Maelstrom with over $7.10M in funding, ARO Network is a premier Decentralized Physical Infrastructure Network (DePIN). It operates as a decentralized edge-cloud platform, aggregating idle internet bandwidth, storage, and compute power from everyday devices worldwide.

The primary objective of ARO is to drastically reduce the cost and increase the speed of heavy AI workloads (specifically Agentic AI) and CDN (Content Delivery Network) routing. Instead of relying on expensive, centralized data centers, ARO routes these tasks across a massive distributed infrastructure network that already boasts over 1.5 million established nodes.

Hardware Support & Operational Layers

ARO Network is designed for maximum accessibility, allowing users to contribute through four distinct hardware layers:

🌐 ARO Lite (Browser Extension)

The easiest barrier to entry. Users can participate by simply installing a lightweight browser extension that shares minimal idle bandwidth while surfing the web.

📱 ARO Mobile (App)

A dedicated mobile application designed to harness the computing capabilities of smartphones, allowing users to earn rewards on the go without draining battery life.

💻 ARO Desktop & Server (Client)

For standard and pro users. Install the dedicated software client on a PC, or deploy the bare-metal workstation image (Server) to contribute heavier CPU/GPU processing power.

🔌 ARO Pod (Dedicated Hardware)

ARO offers proprietary, plug-and-play hardware devices known as the ARO Pod and ARO Link, engineered to run 24/7 for maximum network efficiency and reward generation.

Reward Systems & The $ARO Economy

$ARO is the native utility token governing the entire network. The ecosystem features one of the most aggressive and sustainable tokenomics models in the DePIN sector:

💎 Jade Rewards (Testnet Phase)

Currently in Testnet Season 2 (S2), node operators are rewarded with "Jade Points" for running nodes, sharing bandwidth, and completing AI tasks. A 15% referral commission also boosts your Jade accumulation.

🔄 Mainnet Token Conversion

As the network transitions to its official Mainnet, all accumulated Jade points will be directly converted into liquid $ARO tokens.

🔥 Revenue Buy & Burn Model

ARO employs a deflationary engine. 100% of the fiat revenue generated from enterprise clients using the network is used to market-buy $ARO tokens. Crucially, 90% of these purchased tokens are instantly burned, permanently reducing supply.

🏛️ GPoS Keeper Node Staking

The network utilizes a Guarantee Proof of Stake (GPoS) consensus. Keeper Nodes must stake $ARO as collateral to validate workloads and maintain security, earning network fees while preventing malicious behavior via slashing.

Network Rules & IP Requirements

To maintain node health and ensure your Jade rewards are tracked accurately, please adhere to these connection guidelines:

⚠️ Mandatory Infrastructure Rules:

1. Residential IPs Preferred: The network demands genuine residential Wi-Fi or broadband connections. While explicit blocking metrics for Data Center VPS usage are not heavily publicized, the algorithm prioritizes authentic residential bandwidth for CDN delivery.

2. Global Accessibility: There are zero geographic restrictions. The network is completely borderless, allowing nodes from any region to connect, route data, and earn rewards based on local demand.
